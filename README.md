# learning-os-from-arduino

『つくりながら学ぶ！ リアルタイムOS自作入門』（矢野倉伊織、マイナビ出版）のサンプルコードです。
書籍に載っている手順のまま使えます。

```bash
git clone https://github.com/iory/learning-os-from-arduino.git
cd learning-os-from-arduino/docs/os-on-arduino/code
```

- **サポートページ**（環境構築・章ごとの動作確認・四脚ロボット・FAQ）: https://iory.github.io/build-your-own-arduino-rtos/
