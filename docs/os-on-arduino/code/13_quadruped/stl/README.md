# stl — 印刷する 3 部品

第13章の機体のフレーム。**この 3 ファイルで全部**で、必要な数はこう。

| ファイル | 個数 | 外形 [mm] | 実体積 |
|---|---|---|---|
| `body.stl` | 1 | 250.0 × 110.0 × 50.0 | 239.8 cm³ |
| `thigh.stl` | **4** | 74.3 × 52.0 × 61.2 | 42.9 cm³ |
| `foot.stl` | **4** | 105.7 × 12.0 × 91.5 | 17.5 cm³ |

**左右の作り分けは要らない。** 元の CAD は 4 本の脚それぞれに別ファイルを持っている
が、頂点数も距離分布も完全に一致する。鏡像ですらないので、同じファイルを 4 回刷る。

印刷の設定、ベッドサイズの制約、出力代行に出す場合、そして**刷ったものの質量が
シミュレータのモデルと違う**ことについては [../BOM.md](../BOM.md) を見ること。

**単位はミリメートル。** 元データは `arduino_os_quad_robot`（URDF / MJCF / メッシュ一式）の
`mjcf/assets/` にあり、そちらは MuJoCo に合わせて**メートル**で書かれている。STL の
フォーマット自身に単位の情報が無く、スライサはミリと解釈するので、そのまま渡すと
250 mm の胴体が 0.25 mm の点として読まれ、「No layers were detected」で弾かれる。
ここに置いてあるのは 1000 倍してミリに直したもので、形状は同一。
